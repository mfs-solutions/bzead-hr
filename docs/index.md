## Welcome to the Beauzead Ltd HR Demo

The Beauzead Ltd HR demo presents sample screens for employee management, leave tracking, payroll, and expense claims. It runs entirely in the browser with in-memory demo data.

### Key Features

- **Dashboard** - Real-time HR metrics and pending approvals
- **Staff Directory** - Complete employee database with search and filters
- **Leave Management** - Request and approval workflow with balance tracking
- **Payroll** - Singapore CPF calculations and PDF payslip generation
- **Expense Claims** - Category-based submission with receipt uploads
- **Calendar** - Event management with color-coded categories

## About

This frontend demo does not include authentication, a database, or an API. Changes to sample data are temporary.

### Tech Stack

- React and TypeScript
- Vite
- Tailwind CSS
- React Router
