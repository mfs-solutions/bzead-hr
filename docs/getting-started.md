# Getting Started
{: .no_toc }

Run the frontend-only HR demo locally and explore its sample screens.
{: .fs-6 .fw-300 }

## Run locally

1. Install Node.js and npm.
2. From the project root, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL printed by Vite.

## Navigate the demo

Use the sidebar to browse the dashboard, employee directory, leave requests,
expense claims, payroll, and calendar.

## Demo limitations

This app has no login, backend, database, chatbot, or persistent storage. It
uses sample records only. Leave and expense approvals are temporary browser
state, and payslip PDFs are generated from sample data.

Do not enter real employee, leave, expense, or payroll information.
